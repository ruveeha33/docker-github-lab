# Docker & GitHub Lab

A learning workspace for Docker and GitHub workflows.

## Start here

```bash
git clone https://github.com/ruveeha33/docker-github-lab.git
cd docker-github-lab
git switch -c lab/first-container
```

Implement one exercise at a time. Add setup steps, expected outputs, actual results and limitations before marking it complete.
